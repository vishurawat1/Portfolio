# Certificate Files Directory

Place your certificate files (PDFs or images) in this directory:

- `aws-technical-essentials.pdf` (AWS Technical Essentials)
- `aws-certified-cloud-practitioner.pdf` (AWS Certified Cloud Practitioner)
- `marketing-analytics.pdf` (Marketing Analytics)
- `google-it-support.pdf` (IT Support Certificate)
- `bits-and-bytes-computer-networking.pdf` (The Bits and Bytes of Computer Networking)
- `oracle-certified-foundation-associate.pdf` (Certified Foundation Associate)
- `deloitte-technology-job-simulation.pdf` (Technology Job Simulation)

Alternatively, you can replace the local file path links in `src/components/Certificates.tsx` with external credential URLs (e.g. Credly, Coursera, NPTEL, etc.).
